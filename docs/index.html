Mac

Apple Silicon · macOS 14+ · See the DMG size on the release page

  1. 1

    Move Floe into Applications.

    Open the DMG, drag Floe into Applications, and eject the disk image.

  2. 2

    Open it once.

    This preview is not Apple-notarized. If macOS blocks it, follow the steps below.

    “Floe.app” Not Opened?
    1. Click Done, rather than Move to Trash.
    2. Open System Settings → Privacy & Security.
    3. Find the Floe warning, click Open Anyway, authenticate, then confirm Open.

    Only approve the download from this repository. Managed Macs may restrict this option.

  3. 3

    Allow three permissions.

    Use the Allow buttons in Floe’s settings, then enable Floe in each permission list.

    MicrophoneHear your voiceInput MonitoringDetect the shortcutAccessibilityInsert your words
    Floe isn’t in the permission list?

    For Input Monitoring and Accessibility, drag Floe from Applications into the list and enable it. You can also drag the icon from Floe’s settings. Quit and reopen Floe if macOS asks, or if the shortcut doesn’t respond.

  4. 4

    Give the Globe key to Floe.

    In System Settings → Keyboard, set “Press Globe key to” to Do Nothing. Focus a text field, press Globe / Fn to start, speak, and press again to finish. Hold-to-talk and custom shortcuts are available in Floe’s settings.

Android

Android 8.0+ · Universal APK · About 218 MB

  1. 1

    Install the APK.

    Download Floe for Android, open the APK, and allow installation from your browser or file manager if Android asks. This is a debug-signed preview distributed outside Google Play.

  2. 2

    Enable microphone and accessibility.

    Open Floe, grant microphone permission, read the accessibility disclosure, and enable Floe in Android Accessibility settings. Allow notifications so Floe can show its status.

    Android blocks the accessibility switch?

    On Android 13 or later, open Floe’s App info, open the menu, and select Allow restricted settings if available. Then return to Accessibility settings. Only allow a build you trust; managed devices may restrict this option.

  3. 3

    Tap the ice. Speak into your field.

    Return to Floe and enable it. Focus a text field, tap the floating ice to start, wait for the red indicator, and speak. Tap again to finish. You can also hold to speak or drag the ice to move it. Your normal keyboard stays in place.

A few things to know.

Does Floe need an internet connection?

Not for speech recognition. Both downloads include the model. Mac has optional Bedrock text rewriting, off by default; enabling it sends the final transcript and hotwords to AWS. Building from source requires internet access.

What does Floe store?

Neither platform saves audio. Mac stores local transcript history by default; you can turn it off or clear it in Settings. Android stores preferences but no transcript history. Clipboard managers can see text copied by Floe.

Why do permissions sometimes need to be granted again?

The Mac preview uses ad-hoc signing, so updates can require granting permissions again. Apple notarization is not configured. Android uses a debug signing key; an incompatible update may require uninstalling, which clears preferences and permissions.

Are the two versions identical?

Both use the same bilingual offline speech model. Mac also has hotwords, local transcript history and optional text rewriting. Android uses a floating control and accessibility insertion; hotwords and correction learning are not implemented.

Can I look at the source or report a problem?

Yes. Browse the repository or open an issue. A license for Floe’s own source has not yet been selected; bundled dependencies carry their own licenses.
