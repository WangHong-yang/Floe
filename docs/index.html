Apple Silicon · macOS 14+ · About 141 MB

  1. 1

    Move Floe into Applications.

    Open the DMG, drag Floe into Applications, and eject the disk image.

  2. 2

    Open it once.

    This preview is not Apple-notarized. If macOS blocks it, follow the steps below.

    “Floe.app” Not Opened?
    1. Click Done, rather than Move to Trash.
    2. Open System Settings → Privacy & Security.
    3. Find the Floe warning, click Open Anyway, authenticate, then confirm Open.

    Only approve the download from this repository. Managed Macs may restrict this option.

  3. 3

    Allow three permissions.

    Use the Allow buttons in Floe’s settings, then enable Floe in each permission list.

    MicrophoneHear your voiceInput MonitoringDetect the shortcutAccessibilityInsert your words
    Floe isn’t in the permission list?

    For Input Monitoring and Accessibility, drag Floe from Applications into the list and enable it. You can also drag the icon from Floe’s settings. Quit and reopen Floe if macOS asks, or if the shortcut doesn’t respond.

  4. 4

    Give the Globe key to Floe.

    In System Settings → Keyboard, set “Press Globe key to” to Do Nothing. Focus a text field, hold Globe / Fn, and speak. Right Option is available as an alternate.

A few things to know.

Does Floe need an internet connection?

Not for dictation. The download includes the speech model. Building from source requires a connection to download dependencies.

What does Floe store?

Preferences and hotwords stay on your Mac. Audio and transcript history are not saved. Dictation uses the clipboard, so clipboard managers can see the final transcript.

Why do permissions sometimes need to be granted again?

This preview uses ad-hoc signing. Updates can require granting permissions again. Developer ID signing and Apple notarization are not configured yet.

Can I look at the source or report a problem?

Yes. Browse the repository or open an issue. A license for Floe’s own source has not yet been selected; bundled dependencies carry their own licenses.
