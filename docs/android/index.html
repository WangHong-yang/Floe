  1. 1

    Install Floe.

    Download and open the APK. If Android asks, allow installation from your browser or file manager.

  2. 2

    Allow microphone and accessibility.

    Open Floe, allow microphone access, read the accessibility disclosure, and enable Floe in Android Accessibility settings. Allow notifications to see Floe’s status.

    Accessibility is blocked?

    On Android 13+, open Floe’s App info, open the menu, and choose Allow restricted settings if available. Then return to Accessibility settings. Only allow a build you trust. Managed devices may restrict this option.

  3. 3

    Enable Floe and focus a field.

    Return to Floe and enable it. Once the ice is ready, tap or hold it. Wait for the red indicator before speaking. Tap again or release your hold to finish.

Before you install.

Does my audio leave the phone?

No. Android speech recognition runs locally. Floe Android has no Internet permission, saves no audio or transcript history, and stores only preferences. Fallback clipboard text may be visible to clipboard managers.

Does it work in every app?

Floe writes into accessible text fields, excluding password fields. Some custom editors block automatic insertion; Floe can copy the final text for manual paste. It doesn’t replace your keyboard.

Is this the same as Floe for Mac?

Both use the same bilingual offline speech model. Android uses a floating control. Hotwords, correction learning, transcript history and optional text rewriting are currently Mac features.

Is this a preview release?

Yes. This is a debug-signed preview distributed outside Google Play. This rebuilt 0.0.1 package has not been tested on a phone or emulator. Some custom editors may require manual paste.

Can I see the source?

Yes. Browse the Android source or report a problem. A project-wide license has not yet been selected; dependencies have their own licenses.
